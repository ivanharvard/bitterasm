# `formats`

[`std`](../index.md) › `formats`

| Name | Summary |
|---|---|
| [`elf`](elf.md) | ELF static executables, for Linux and the BSDs. |
| [`ihex`](ihex.md) | Intel HEX: an image as lines of text, the format microcontroller programmers like avrdude read. Each line is a record: `:`, its length, address and type, up to 16 data bytes, and a checksum, all in hex. |
| [`macho`](macho.md) | Mach-O 64 executables, for macOS. |
| [`pe`](pe.md) | PE32+ (64-bit Windows) console executables. |
